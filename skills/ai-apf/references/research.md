# 科学问题形成

把本模块用于科学意图、证据目标或可行性尚不明确的步骤。已有明确问题的绘图、代码修改和计算直接推进；困难的推导可以需要深入推理，无需重新选题。把以下内容作为可选检查视角，按当前缺口使用，不逐项盘问。

## 1. 先找到关注点

保留用户原始观察、比喻或疑问。提出容易被否定和修改的暂定理解，并明确这是模型的猜测。先帮助区分用户可能在意的现象，再展开研究路线；用户尚未选择时，不把某个解释、较小问题或描述性目标当成既定意图。候选理解尽量使用用户能辨认的画面或关系，例如“同一处变得更密”和“不同地方先后活动”；此时无需先证明对应机制在该领域存在。

用能帮助用户辨别的解释收束首轮，再留下最关键的纠正入口；不要把候选问题、探索方案和退出判断一次全部输出。必要的概念解释可以充分展开，例如用一个反例说明“先后发生”与“直接影响”的差别，不能只抛术语或选项要求用户自选。用户明确要求完整分析或关注点已清楚时直接深入，不把“先辨别关注点”变成每轮必须通过的关卡。用户纠正后只更新受影响的判断。

区分三个层次：长期关切、当前拟研究的问题、下一步动作。缩小当前动作时说明它能为原始关切提供什么，不能默认用一个容易完成的任务替代原目标。

## 2. 针对缺口选择动作

| 当前缺口 | 优先动作 |
| --- | --- |
| 表达含混 | 给少量候选理解或具体例子，让用户纠正；避免替用户断言意图。 |
| 概念不足 | 解释足以作出当前选择的概念及区别，再回到问题。 |
| 背景知识不足 | 先明确哪项事实会改变当前理解或选择，再围绕它检索可靠资料；不因用户尚不熟悉术语就默认补一轮领域综述。 |
| 证据不足 | 读取已有材料，或提出有边界的探索性检查；允许暂时无法区分。 |
| 数据、方法、资源条件不明 | 核查决定可行性的条件，区分可获得、已获得、可使用和已验证。 |
| 目标或取舍未定 | 比较收益、代价和放弃的内容，给建议及理由，由研究者选择。 |

用户回答“还不知道”时，换用例子、材料、概念解释或低成本探索，不重复要求其提供同一答案。能从已授权材料获得的信息先自行检查。一次优先问最影响下一步的问题，不要求用户先学会专业措辞。

查询的作用应可说清：结果不同，会怎样改变当前理解、候选问题或下一步？若只能增加背景，而不会影响这一步，先延后。用户明确要求查证、现有材料的识别或解释依赖专业事实、或必要概念不能可靠解释时，应及时核查，不必等用户先选定方向。领域关键词本身不构成加载领域工作流或追溯旧项目的理由；已有上下文确能减少当前歧义时再补读。假想例子须保持假想，不借它暗示真实事件已发生或某机制已成立。

关注点足够清楚后，可按当前疑问选择遗漏检查视角：操作定义、参照与基线、观测或处理效应、样本选择、分辨能力、解释可区分性。只展开会改变当前判断的项，并说明它与问题的关系；不要逐项遍历，也不在粗糙直觉的首轮自动生成检查清单。已有材料能够回答时先读材料；缺少材料时保留待核查状态，不把通用风险当成已发现的问题。

## 3. 形成确有区别的候选问题

需要比较时，选择少量真正改变研究对象、证据要求或结论范围的框架。无需凑候选数量。对每个重要候选说明：想知道什么、为什么值得知道、什么观察或结果能推进它、现有条件能支持什么。

允许描述、分类、测量、方法开发、预测和机制判别各自成为终点。依据任务选择质量标准，不要求一律提出因果解释。检验价值时区分新措辞、观测改善、方法贡献和新增知识；必要时核查已有研究，不能仅凭模型印象宣布新颖或无价值。

重要科研方向取舍时，按本次决定的需要比较：问题的重要性、相对已有工作的增量、现有条件下的可行性、与研究者或团队目标的契合，以及不同结果能带来什么信息。阴性或不支持预期的结果是否有价值，要看它能约束什么；区分能力不足的结果不自动构成有意义的否定。未知项保持未知，指出何时值得核查，不默认追加完整文献调研，也不要求每次填齐所有维度。

任务确实涉及导师或合作者的要求时，区分研究者自身目标、研究者转述的他人要求、已确认的共同决定和仍未确认的约束；转述不能自动升级为对方已确认。出现影响方向的冲突时，指出具体取舍及需要谁确认，不替任何一方决定，也不要求普通单人任务做一轮多方意图访谈。

主动提出与当前判断相关的竞争解释、反例或失败情形。数据条件检查与条件性的科学讨论可以并行；只把真正阻断下一步的条件设为门槛，避免无限检查或无依据扩大联合观测范围。

## 4. 维护证据与判断边界

在重要主张处区分用户报告、实际核查结果、研究者选择、模型推断和待验证假设；无需给每句话加标签。外部知识给可追溯来源及适用范围，无法核实时保留不确定性。检查材料日期、数据版本或方法假设中会影响结论的部分。

汇报检查时说明查了什么、结果如何、支持到哪一步、还有什么未知。做过坐标检查不等于排除观测效应；算出一个量不等于其物理解释已成立。不能把形态对应、相关或先后顺序直接写成机制证据，也不能把两个模型意见一致当成验证。

## 5. 用有限探索推进

提出探索方案时交代目的、材料或方法、投入边界、预期可观察产物，以及什么结果会结束或改变下一步。边界可以是一个样例、一组关键来源或一次必要计算；预算依据错误方向的代价和初步验证难度确定。40/100 仅表达愿意投入，不设为固定比例，也不用对话长度衡量投入。

会影响方向的小检查，在开始前说明相关的支持、不支持或暂时无法判断的结果分别会改变哪项判断或下一步，不必穷举所有结果或编造阈值。检查未检出、结果不稳定或分辨能力不足时，先判断能支持到哪里，不能直接写成现象或机制不存在。检查后依据实际支持更新受影响的前提，保留其余仍有效的判断；一次检查正常不代表所有竞争解释已排除。

科研方向、重要目标调整和实质增加的探索投入由研究者选择；先把建议做得具体可评审。已批准范围内的阅读、核查和实现持续推进，不重复申请批准。

在重要选择处简述选择理由、代价和证据边界，让用户修正；需要时用一个反例或结果情景帮助其辨别理解。不要把强制复述或考试设为低成本探索的前提。

## 6. 判断何时前进、退出或回退

持续观察是否获得了可用成果：歧义被消除、概念区别明确、关键前提得到核查、候选取舍更清楚、可行范围收窄，或下一步验证变得具体。若讨论只在改写措辞，改变动作：接触材料、缩小当前投入或暂止。

问题与证据目标足以指导下一步、关键风险已有处理方式、完成及返回条件明确时，开始执行；无需消除所有未知。条件未明但可低成本查清时先探索。证据能力弱于原目标时提出缩小或改向，保留原目标及取舍理由。价值不足、成本过高或条件无法核查时允许暂止。

执行发现新证据时，明确哪项前提变化、影响哪些结论和动作；只重开受影响分支。交付时留下当前问题、选择理由、已核查条件、未决事项和下一步验证，复用已有记录，不额外制造维护负担。

## 假设示例

用户说“图中极光亮度结构似乎在移动，我想知道为什么”。先辨别关注的是结构外观变化、位置变化，还是不同区域依次活动；这些都是候选理解。读取图像和时间信息后，当前目标可以是形态描述、运动学测量、观测效应检查或机制比较。若只有截图，可以先讨论不同解释各需什么证据；若序列计时未知，先核查它是否支持所需时序。说明每一步与“为什么动”的关系，保留暂时无法区分的可能，不预定必须得到某个机制。相同原则也适用于生物图像变化、材料结构演化或数值模型异常。
